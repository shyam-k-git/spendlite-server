# SpendLite Server 💳

The backend REST API service for **SpendLite** — a personal expense tracking application. Built with Node.js, Express, TypeScript, Prisma 7, and PostgreSQL.

---

## 🚀 Features

- **Strict TypeScript:** 100% strictly typed request/response handlers with no runtime type assertions.
- **RESTful Endpoints:** Full CRUD support for expenses and category lookup.
- **Data Validation:** Runtime schema validation using **Zod** (ensuring bounds, string sanitation, and 2-decimal currency limits).
- **Relational Integrity:** Foreign key constraints with explicit database error mapping.
- **Database ORM:** Powered by **Prisma 7** with native PostgreSQL driver adapter (`@prisma/adapter-pg`).

---

## 🛠️ Tech Stack

- **Runtime:** Node.js (ESM `NodeNext`)
- **Framework:** Express 5
- **Language:** TypeScript 7
- **Database & ORM:** PostgreSQL, Prisma 7
- **Validation:** Zod
- **Development Tooling:** `tsx` for hot-reloading dev server

## 📦 Getting Started

### 1. Prerequisites

- **Node.js:** v20.x or higher
- **PostgreSQL:** v14.x or higher running locally or in Docker

### 2. Installation

```bash
cd spendlite-server
npm install
```

### 3. Environment Setup

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

Configure your `.env` file:

```env
DATABASE_URL="postgresql://postgres:password@localhost:5432/spendlite?schema=public"
PORT=9000
```

### 4. Database Setup & Migrations

Run database migrations to initialize tables:

```bash
npx prisma migrate dev
```

Seed default categories (*Food*, *Travel*, *Shopping*):

```bash
npm run seed
```

### 5. Running the Server

#### Development Mode (with hot-reload):
```bash
npm run dev
```

#### Production Build & Start:
```bash
npm run build
npm start
```

#### Typecheck:
```bash
npm run typecheck
```

## 📡 API Reference

Base URL: `http://localhost:9000`

### Health Check
- **`GET /health`**
  - Response `200 OK`: `{"status": "ok"}`

### Categories
- **`GET /api/categories`**
  - Response `200 OK`: Array of category objects.
  ```json
  [
    { "id": 1, "name": "Food" },
    { "id": 2, "name": "Travel" },
    { "id": 3, "name": "Shopping" }
  ]
  ```

### Expenses
- **`GET /api/expenses`**
  - Returns all recorded expenses ordered by date descending.
  - Response `200 OK`: Array of expenses with relations.
  ```json
  [
    {
      "id": 1,
      "title": "Lunch",
      "amount": 250.00,
      "date": "2026-10-26",
      "categoryId": 1,
      "category": { "id": 1, "name": "Food" }
    }
  ]
  ```

- **`POST /api/expenses`**
  - Request Body:
    ```json
    {
      "title": "Groceries",
      "amount": 450.50,
      "date": "2026-10-26",
      "categoryId": 1
    }
    ```
  - Response `201 Created`: The newly created expense.
  - Response `400 Bad Request`: Validation failure or category does not exist.

- **`DELETE /api/expenses/:id`**
  - Response `204 No Content`: Successfully deleted.
  - Response `400 Bad Request`: Invalid ID.
  - Response `404 Not Found`: Expense not found.
